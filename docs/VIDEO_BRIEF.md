# Video brief: Auto Game Installer

Give this whole file to the AI agent or video tool, along with the repo link:
https://github.com/Alrayyanumar56/Auto-Game-Installer

## What the project is (plain words)
A free, open-source Windows app. You download a game with qBittorrent and leave your PC on overnight. When the download finishes, the app runs the game's setup by itself, so the game is already installed when you wake up. It queues installs, can mute the installer's sound, and can shut the PC down when everything is done.

## The one message
**Download at night. Wake up to a game that's ready to play.**

## Audience
PC gamers who download large games and hate waiting for the install in the morning. Also developers who like small useful automation projects.

## Look and feel (use exactly these)
- Background: night navy `#0B1020` (gradient to `#141B2E`)
- Accent (use once per scene, for the important thing): mint `#3DDC97`
- Text: `#E8EEFF`, secondary text `#8A94B2`
- Font: Inter (or Segoe UI). Clean, lots of empty space, no clutter.
- Logo: `assets/icon.png`. Banner: `assets/banner.png`.
- Mood: calm, night-time, then a satisfying "it's done" moment. Not loud, not "hacker green on black".

## Structure (30 to 45 seconds)
1. **Hook (0-3 s).** Text on screen: "I made my PC install games while I sleep." Moon icon fades in.
2. **Problem (3-9 s).** Show a download finishing at 3:07 AM, and nothing happening. Text: "Download done. Now you still have to install it."
3. **Setup (9-18 s).** Screen recording of the app: pick the games folder, tick the options, click Set Up. Text: "Set it up once."
4. **Night (18-26 s).** Clock moves from night to morning. The queue runs two installs, one after the other.
5. **Payoff (26-36 s).** Morning. The installer window says it finished. The game's launcher is ready. Text: "Wake up. Press play."
6. **Call to action (36-45 s).** Logo + "Free and open source. Windows + qBittorrent." and the repo link `github.com/Alrayyanumar56/Auto-Game-Installer`.

## Rules
- Use screen recordings of the real app, not mock-ups.
- Do not name any specific games, repack groups or piracy sites. Say "a game" or use a free/indie title.
- Captions on every scene (most people watch muted). Music: soft, ambient, low volume.
- Say it is an early release: Windows + qBittorrent only.
- Deliver three sizes: 16:9 (GitHub, LinkedIn, YouTube), 9:16 (Instagram, TikTok, Shorts), 1:1 (Facebook).
